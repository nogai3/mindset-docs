## Characteristic IDs for Mindset Minecraft mod. <br> ID характеристик для Minecraft мода Mindset.
This document actual for Mindset versions: mindset-1.1.0-daily16092026 and newer.. <br> Этот документ актуален для версий Mindset: mindset-1.1.0-daily13092026 и новее...

Optimist (Оптимист) **- ID: optimist**<br>
Workaholic (Трудоголик) **- ID: workaholic**<br>
Gourmet (Гурман) **- ID: gourmet**<br>
Fearless (Бесстрашный) **- ID: fearless**<br><br> 

Claustrophobic (Клаустрофобия) **- ID: claustrophobic**<br>
Suspiciousness (Мнительность) **- ID: suspiciousness**<br>
Self Flagellation (Самобичевание) **- ID: self_flagellation**<br>
Apathy (Апатия) **- ID: apathy**<br><br>

To add characteristic use command: **/mindset attribute add <characteristic id>**<br>
To remove characteristic use command: **/mindset attribute remove <characteristic id>**<br>
To check your characteristic use command: **/data get entity <Entity> Characteristics**<br><br>

Для добавления характеристики используйте команду: **/mindset attribute add <id характеристики>**<br>
Для того чтобы убрать характеристику используйте команду: **/mindset attribute remove <id характеристики>**<br>
Для того чтобы посмотреть выбранные характеристики используйте команду: **/data get entity <Сущность> Characteristics**
